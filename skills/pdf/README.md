# PDF Reader Core Skill (Hermes 3D Avatar)

Modul pembacaan dan analisis dokumen PDF bawaan (*built-in mandatory skill*) untuk Hermes 3D Avatar.

## Mengapa Skill Ini Wajib (Core)?
Memungkinkan pengguna menjatuhkan (*drag and drop*) atau meminta avatar membaca file dokumen PDF (buku, jurnal ilmiah, laporan keuangan, manual instruksi). 

Avatar dapat mengekstrak teks, membuat ringkasan eksekutif, dan menjawab pertanyaan berdasarkan isi dokumen secara cepat dan akurat.
