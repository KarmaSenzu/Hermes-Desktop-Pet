# Open Application Core Skill (Hermes 3D Avatar)

Modul peluncur aplikasi sistem bawaan (*built-in mandatory skill*) untuk Hermes 3D Avatar.

## Mengapa Skill Ini Wajib (Core)?
Memungkinkan avatar bertindak sebagai asisten desktop nyata: pengguna cukup berkata *"Buka Notepad"*, *"Nyalakan VS Code"*, *"Buka Spotify"*, atau *"Tampilkan kalkulator"*, dan avatar akan meluncurkan aplikasi yang diminta secara aman di sistem operasi pengguna.
