# Weather 2.0 Core Skill (Hermes 3D Avatar)

Modul pemantauan cuaca dan prakiraan real-time bawaan (*built-in mandatory skill*) untuk Hermes 3D Avatar.

## Mengapa Skill Ini Wajib (Core)?
Memungkinkan avatar memberikan laporan cuaca akurat, suhu, kelembaban, serta saran busana atau aktivitas harian untuk kota mana pun di dunia saat pengguna menyapa avatar di pagi atau sore hari.
