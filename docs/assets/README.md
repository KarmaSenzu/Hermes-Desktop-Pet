# Assets Media & Showcase

Direktori ini disiapkan untuk menyimpan media visual (tangkapan layar, demo GIF, dan video pendek) yang ditampilkan pada `README.md` utama di GitHub.

## Panduan Penempatan File Media

Untuk menjaga keterbacaan dan waktu muat halaman yang optimal di GitHub:
- **Format Gambar:** PNG atau WebP (disarankan resolusi 1280x720 atau 1920x1080).
- **Format Animasi:** GIF (teroptimasi < 10MB) atau cuplikan video MP4 / WebM.
- **Nama File Standar:**
  - `hero-banner.png` — Banner utama atau tampilan saat avatar aktif di desktop.
  - `demo-tiling.gif` — Demonstrasi fitur Tiling Window Manager (pergeseran otomatis jendela).
  - `demo-music-player.png` — Tampilan pemutar musik mini Spotify dengan vinyl berputar.
  - `demo-settings.png` — Tampilan jendela pengaturan macOS-style dan kustomisasi animasi.
  - `demo-doctor.png` — Tangkapan layar terminal saat menjalankan `npm run doctor`.

Cukup tempatkan file gambar dengan nama di atas ke dalam folder ini, dan `README.md` utama akan otomatis menampilkannya.
