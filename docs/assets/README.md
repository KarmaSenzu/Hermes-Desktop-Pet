# Assets Media & Showcase

Direktori ini disiapkan untuk menyimpan media visual (tangkapan layar, demo GIF, dan video pendek) yang ditampilkan pada `README.md` utama di GitHub.

## Panduan Penempatan File Media

Untuk menjaga keterbacaan dan waktu muat halaman yang optimal di GitHub:
- **Format Gambar:** PNG atau WebP (disarankan resolusi 1280x720 atau 1920x1080).
- **Format Animasi:** GIF (teroptimasi < 10MB) atau cuplikan video MP4 / WebM.
- **Daftar File Aktif di README.md Utama:**
  - `hero-desktop-live.jpeg` (atau `1.jpeg`) — Banner utama tampilan nyata desktop macOS dengan karakter Live2D Camellya, HUD dock, Chat AI, Screen Vision, dan Music Player.
  - `showcase-home-status.jpeg` (atau `2.jpeg`) — Tampilan panel Home dengan checklist status kesiapan sistem 5/5.
  - `showcase-characters.jpeg` (atau `3.jpeg`) — Tampilan galeri pustaka karakter Live2D tersimpan (Mother, Jingliu, HuoHuo, Sparkle, Ellen Joe, Jane Doe, Camellya, Allium).
  - `showcase-voice-tts.jpeg` (atau `4.jpeg`) — Tampilan panel Suara & TTS (Kokoro-TTS anime seiyuu & Whisper STT).
  - `showcase-llm-provider.jpeg` (atau `5.jpeg`) — Tampilan panel LLM & Multi-Provider AI (Dual-Track OAuth, 9Router, monitor kuota).

Cukup tempatkan file gambar dengan nama di atas ke dalam folder ini, dan `README.md` utama akan otomatis menampilkannya.
