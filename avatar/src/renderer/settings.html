Hermes Web Companion (Ekstensi Chrome & Edge) Ekstensi browser Ask AI pendamping — klik kanan atau Alt+A untuk merangkum web langsung ke Avatar
… ▾
Tipe: Manifest V3 Unpacked Extension · Kompatibel: Chrome, Edge, Brave, Opera

Pasang ekstensi ini ke browser Anda hanya dalam 3 langkah mudah:

1
Buka halaman ekstensi di browser: ketik chrome://extensions (atau edge://extensions).
2
Aktifkan toggle "Developer mode" di pojok kanan atas layar ekstensi browser Anda.
3
Klik tombol "Load unpacked" (Muat yang belum dibongkar) di Chrome/Edge, lalu arahkan dan pilih folder chrome (folder ekstensi) dan klik tombol "Select" / "Pilih".
Panduan Memuat di macOS & Windows:
• Pilih Foldernya Langsung: Browser hanya meminta Anda memilih satu folder (jangan buka atau seret file satuan di dalamnya). Klik folder chrome lalu klik tombol "Select" / "Pilih" / "Buka" di jendela file picker browser.
• Shortcut macOS: Saat jendela pemilih file browser terbuka, tekan Cmd + Shift + G, lalu tempel (paste) path yang disalin dari tombol di bawah.
Port Bridge Lokal: 9124 · Status: Memeriksa…

Fitur Ekstensi:
  • Shortcut Cepat: Tekan Alt + A di browser untuk langsung menanyakan teks yang diblok ke avatar.
  • Context Menu: Klik kanan teks apa pun → pilih "Tanyakan ke Hermes Avatar" atau "Rangkum Halaman Ini".
  • Rangkuman Otomatis: Jawaban muncul seketika di panel chat avatar, lengkap dengan pembacaan suara & animasi bibir!
