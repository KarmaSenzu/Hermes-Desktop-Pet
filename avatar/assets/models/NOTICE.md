# Direktori Model 3D Kustom

Folder ini disiapkan bagi pengguna yang ingin menambahkan atau menggunakan model 3D kustom:
- Format yang didukung: `.vrm` (VRoid / VRM 0.x & 1.0), `.glb`, `.gltf`, `.pmx`, `.pmd` (MMD).
- Jika Anda memiliki model VRM default, Anda dapat menamai berkas tersebut sebagai `default.vrm` dan meletakkannya di sini.
- Anda juga dapat memilih berkas model secara interaktif melalui jendela Pengaturan (*Settings*) pada tab **Karakter**.
