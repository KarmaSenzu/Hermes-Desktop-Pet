# Pemberitahuan Lisensi & Atribusi Audio Karakter

Berkas suara dan sampel audio vokal pada direktori ini (`avatar/assets/audio/mother/`) menyertai model karakter Mother untuk keperluan pembelajaran (*study*), integrasi respons avatar, dan penggunaan harian non-komersial.

## Ketentuan Penggunaan
* **Non-Komersial:** Dilarang keras memperjualbelikan berkas audio ini dalam bentuk apa pun.
* **Atribusi & Hak Cipta:** Hak cipta asli audio tetap menjadi milik pengembang game indie di Steam: [**Your Mother**](https://store.steampowered.com/app/3399950/Your_Mother/) (App ID: `3399950`).
* **Dukungan:** Dukung developer aslinya dengan memainkan game resminya di Steam: [https://store.steampowered.com/app/3399950/Your_Mother/](https://store.steampowered.com/app/3399950/Your_Mother/).
* Pengguna dipersilakan mengganti atau mengimpor file audio vokal mandiri kapan saja melalui menu Pengaturan.
