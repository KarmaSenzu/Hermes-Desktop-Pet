# Kokoro TTS Local Synthesis Core Skill (Hermes 3D Avatar)

Modul integrasi sintesis vokal lokal performa tinggi (*built-in neural TTS skill*) untuk Hermes 3D Avatar.

## Mengapa Skill Ini Wajib (Core)?
Menghubungkan avatar dengan model neural vokal Kokoro-82M di port 8880 lokal. Mendukung pelafalan bahasa Indonesia dengan intonasi anime yang jernih, imut, dan ekspresif tanpa memerlukan koneksi internet, serta otomatis fallback ke Edge-TTS jika server lokal offline.
