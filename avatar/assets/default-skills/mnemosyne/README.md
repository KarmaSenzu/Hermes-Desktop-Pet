# Mnemosyne Core Skill (Hermes 3D Avatar)

Modul memori jangka panjang bawaan (*built-in mandatory skill*) untuk Hermes 3D Avatar.
Repository hulu: [mnemosyne-oss/mnemosyne](https://github.com/mnemosyne-oss/mnemosyne.git)

## Mengapa Skill Ini Wajib (Core)?
Setiap pengguna mungkin memasang skill berbeda-beda untuk avatar mereka. Namun, kemampuan mengingat percakapan, preferensi pengguna, dan fakta-fakta penting antar sesi adalah fungsi inti (*core capability*) yang harus dimiliki oleh avatar di komputer siapa pun.

Mnemosyne berjalan 100% lokal di atas SQLite tanpa ketergantungan cloud, menjamin privasi data dan kecepatan inferensi.
