# DuckDuckGo Search Core Skill (Hermes 3D Avatar)

Modul pencarian web bawaan (*built-in mandatory skill*) untuk Hermes 3D Avatar.

## Mengapa Skill Ini Wajib (Core)?
Memungkinkan avatar mencari informasi terkini di internet (berita terbaru, fakta ilmiah, referensi koding, dokumentasi API) secara bebas tanpa memerlukan akun berbayar atau API key pihak ketiga.

Pencarian dilakukan secara instan melalui DuckDuckGo HTML/Instant API yang menghormati privasi dan bebas jejak tracking.
