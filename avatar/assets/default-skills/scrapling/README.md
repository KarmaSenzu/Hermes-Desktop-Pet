# Scrapling Web Extraction Core Skill (Hermes 3D Avatar)

Modul ekstraksi konten web performa tinggi bawaan (*built-in mandatory skill*) untuk Hermes 3D Avatar.

## Mengapa Skill Ini Wajib (Core)?
Saat avatar menemukan URL artikel, dokumentasi, atau halaman web dari pencarian Google/DuckDuckGo, Scrapling mengekstrak teks bersih tanpa gangguan iklan, cookie banner, atau markup HTML berlebih.

Menjamin data yang masuk ke memori penalaran LLM adalah teks murni yang padat dan relevan.
